# OpenRSMods

This is a fork of ["The Rocksmith Mods that nobody asked for"](https://github.com/Lovrom8/RSMods) that nobody asked for.

The version-dispatch system has also been simplfied to only target **Rocksmith 2014 Remastered build 9490972 (v165)** — the current and likely final Steam build. That means no support for old versions, random torrent versions or the Learn & Play edition.

All file integrity / "anti-piracy" / Steam certificate / hash allowlist etc checks have been removed.
